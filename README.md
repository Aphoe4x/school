# School

Small PHP login and registration exercise from school. It has session guard pages, a simple layout folder, and a database connection file.

## Files

- index.php - main entry point
- pages-login.php and pages-register.php - login and register forms
- authenticated.php - logged-in area
- logout.php - ends the session
- database.php - database connection
- layout/ - shared page layout
- assets/ - styles and scripts
